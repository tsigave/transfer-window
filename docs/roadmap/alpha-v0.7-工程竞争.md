# alpha-v0.7「工程竞争」Checklist

## 版本目标

交付模块化舰船设计、造船和商业认证，把研发成果转化为可制造部件；同时开放谷神星与代表性小行星开发，为木星供应链建立工业和中转能力。

**前置依赖：** alpha-v0.6 退出条件全部通过。
**退出产物：** 设计验证器、船厂与订单、技术认证、专业舰型、谷神星及小行星商业网络。

## 工作流 A：模块化舰船设计

- [ ] 定义反应堆、发动机、工质舱、货仓、结构、散热器、屏蔽、自动化、乘员和冗余模块接口。
- [ ] 设计器实时计算干/湿质量、质心约束、货舱、功率、推力、热、结构、辐射、寿命和维护指标。
- [ ] 设计校验返回阻断错误、工作包线限制和余量，不自动修正玩家参数。
- [ ] 支持蓝图修订与差异比较；已建舰船始终引用制造时修订版。
- [ ] 用统一任务集比较速度、载荷、工质、建造成本和生命周期成本，不声明单一最佳设计。

## 工作流 B：船厂、订单与改装

- [ ] 实现船厂尺寸、质量、模块能力、材料、人员和排期限制。
- [ ] 造船订单预留船台和物料，按阶段形成在制品；缺料或许可失效时暂停。
- [ ] 实现购买、委托制造、租赁、改装、试航和交付验收。
- [ ] 新舰船和关键改装需通过规定试航与认证，不合格资产保留问题和返工路径。
- [ ] 船厂容量可由玩家或AI竞标，全部订单与付款进入公开合同和账本。

## 工作流 C：技术认证与专业化

- [ ] 实现 `Certification` 的对象、用途、工作包线、签发方和有效条件。
- [ ] 将至少一条中级研发路线接入散热器原型、轨道测试、认证、生产和安装全过程。
- [ ] 运营数据、事故与极限任务产生条件化证据，能降低后续相关测试风险。
- [ ] 许可过期不影响合法制造的既有资产，但阻止新的受限制造与软件部署。
- [ ] AI能够比较标准舰型与专业设计，并制造至少两种经营定位显著不同的舰型。

## 工作流 D：谷神星与小行星开发

- [ ] 将谷神星、灶神星、灵神星等选定节点设为 `CommercialOpen`，保留其既有天体ID与星历。
- [ ] 配置挥发物、金属、工质、科研和转运市场，不提供无运输来源的需求或库存。
- [ ] 支持采集、加工、仓储、补给、维修与中转设施建设。
- [ ] 提供地月火—谷神星合同、返程货源和窗口组合，使三角贸易可自然形成。
- [ ] AI能评估先建枢纽、锁定燃料、保持轻资产或专注散货等不同策略。

## 接口与存档变更

- 扩展 `ShipBlueprint` 为模块图和修订；新增船厂、造船订单、在制品、试航与认证。
- 技术成果引用可制造部件、工艺或软件修订。
- 存档保存设计历史、在制品物料、船厂排期、认证和谷神星经济状态。

## 自动验证

- [ ] `cargo run -p sim-tools -- ship validate-fixtures` 对合法/非法设计返回稳定结果。
- [ ] `cargo run -p sim-tools -- ship mission-benchmark` 输出标准任务 Pareto 比较且无全维度支配的万能舰型。
- [ ] `cargo run -p sim-tools -- research route medium-radiator` 完成研究、原型、认证、制造、安装全链。
- [ ] `cargo run -p sim-tools -- scenario run ceres-corridor --years 5` 形成可审计的谷神星供应链。
- [ ] 船厂并发、缺料、许可过期和订单取消通过事务与恢复测试。

## 人工验收剧本

1. 设计一艘谷神星散货船，比较不同推力、散热和工质配置。
2. 为设计获取部件许可、预订船厂、运输材料、完成建造与试航。
3. 把新船投入地球—火星—谷神星三角贸易，核对生命周期成本。
4. 观察至少一家AI用不同专业舰型争夺相同区域市场。

## 不纳入本版本

- 木星商业开发、强辐射和大气资源采集。
- 自由几何CAD或逐结构梁搭建。
- 完整自动调度和3D轨道分析。

## 退出条件

- [ ] 设计、认证、制造、改装和实际运营形成闭环。
- [ ] 谷神星及代表性小行星可建设并与内太阳系形成真实货流。
- [ ] 玩家和AI都能制造、运营可解释的专业舰型。
- [ ] 木星远航所需的大型舰船、补给与中转能力已可获得。
