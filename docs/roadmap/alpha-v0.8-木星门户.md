# alpha-v0.8「木星门户」Checklist

## 版本目标

在 alpha-v1.0 前正式开放至少一颗气态巨行星的开发：玩家和AI能够围绕木星轨道、木卫四和木卫三建设设施、争夺资源与合同，并维持地球—谷神星—木星长期供应链。

**前置依赖：** alpha-v0.7 退出条件全部通过。
**退出产物：** 木星开发权限、辐射与深空风险、木卫四枢纽、受限卫星任务、大气采集后期链、自动调度和高级航迹。

## 工作流 A：木星系统规则

- [ ] 将木星轨道、木卫四设为 `CommercialOpen`，木卫三开放受限开发；沿用 alpha-v0.1 的天体ID和历史状态。
- [ ] 木卫一和木卫二保留科研/高风险权限，建设受辐射、安全与剧本许可约束。
- [ ] 建立木星辐射场近似模型，按位置、时间、屏蔽和任务状态累计设备及人员剂量。
- [ ] 实现深重力井、木星局部捕获/离轨与多卫星航段，所有代价来自航迹计算。
- [ ] 实现远距离通信延迟和过期信息标识；单机仍允许玩家下达计划，但不能伪装实时市场情报。

## 工作流 B：木卫四枢纽与资源工业

- [ ] 配置木卫四初始科研前哨、有限泊位、库存、人口和建设权限。
- [ ] 支持仓储、补给、维修、居住、能源、采集与加工设施的分阶段建设。
- [ ] 支持木卫三有限资源与科研任务，并把辐射、许可和维护加入成本。
- [ ] 实现木星轨道平台与后期大气资源采集设施；气态巨行星本体不生成地表基地。
- [ ] 大气采集产物必须经过采集、处理、抬升、储存和运输，不直接进入任意节点库存。
- [ ] 木星本地设施故障或缺料能沿真实供应链影响运价、维修和后续建设。

## 工作流 C：深空运营与自动化

- [ ] 实现区域最低运力、库存目标、安全库存和补给优先级策略。
- [ ] 自动调度从已验证航迹和可用舰船中生成候选，提交前展示成本与冲突。
- [ ] 支持批量接受/分配合同、维护窗口、补给和重复航线模板。
- [ ] 加入单次/多次引力辅助和受约束 Oberth 候选搜索，纳入辐射、热、寿命和时间代价。
- [ ] 建立3D轨道分析视图显示倾角、交点、推力段、弹弓和局部卫星系统；显示不改变模拟。
- [ ] 背景求解支持进度、取消、缓存和稳定归并，不能因并行顺序破坏确定性。

## 工作流 D：研发与AI木星竞争

- [ ] 增加辐射屏蔽、深空可靠性、高功率散热和木星资源工业研发路线。
- [ ] 木星相关认证明确剂量、连续工作时间、冗余和维修条件。
- [ ] AI能评估木卫四先发基地、燃料合同、船队专门化和保持中转贸易等策略。
- [ ] AI与玩家公平争夺泊位、船厂、施工材料、许可、合同和开发位置。
- [ ] 可观察的船厂订单、材料流和基地施工向玩家提供竞争信号，不暴露AI私有计划。
- [ ] 注入木星设施故障后，AI能在规定规划周期内重排补给和维护。

## 接口与存档变更

- 新增辐射环境、剂量、通信数据时刻、区域运力目标和自动调度规则。
- 扩展航迹为多天体辅助与局部卫星航段；保存求解器版本和辅助序列。
- 新增木星轨道/大气设施类型、受限开发许可和外太阳系科研合同。

## 自动验证

- [ ] `cargo run -p sim-tools -- environment jupiter-radiation` 验证剂量随轨迹与屏蔽变化且可重放。
- [ ] `cargo run -p sim-tools -- trajectory jupiter-suite` 覆盖直接、谷神星中转、引力辅助和局部卫星航段。
- [ ] `cargo run -p sim-tools -- scenario run jupiter-supply-chain --years 12` 完成从内太阳系建设到稳定补给。
- [ ] `cargo run -p sim-tools -- ai benchmark --scenario jupiter-race --seeds 100` 通过公平性、响应和生存指标。
- [ ] 大气采集和设施故障场景通过物资、能量、资金和事件因果审计。

## 人工验收剧本

1. 从成熟地月火—谷神星公司准备木星远航，比较直接与辅助航迹。
2. 运送人员、设备和建材到木卫四，分阶段建成补给与维修能力。
3. 执行木卫三资源任务和木卫二科研任务，观察辐射、许可与维护差异。
4. 建设或使用木星轨道大气采集链，确认产物经过完整物流进入市场。
5. 与至少两家AI竞争木星合同和关键容量，并维持两个连续补给周期。

## 不纳入本版本

- 土星、天王星和海王星商业开发。
- 木星“地表基地”或无代价大气资源。
- FTL和程序化恒星系。

## 退出条件

- [ ] 木星系统已是可建设、可生产、可补给和可竞争的气态巨行星开发区域。
- [ ] 地球—谷神星—木星供应链能连续运行两个周期且物资、资金可审计。
- [ ] 辐射、通信、维护和深空航迹对商业决策产生可解释影响。
- [ ] 玩家与AI共同参与的端到端剧本、性能和确定性验证全部通过。
