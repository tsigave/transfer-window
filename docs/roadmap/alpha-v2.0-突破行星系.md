# alpha-v2.0「突破行星系」Checklist

## 版本目标

让成熟太阳系经济通过既有研发、工业、物流和资本系统完成超光速理论验证、巨型原型与第一次可靠恒星际飞行。FTL是全系统汇合的终局，不是点击即生效的科技节点。

**前置依赖：** alpha-v1.x 的外太阳系能力和存档兼容基线通过。
**退出产物：** FTL多理论路线、巨型试验工程、程序化目标星系、首次可靠飞行与可选商业化后续。

## 工作流 A：FTL理论图谱

- [ ] 设计至少三条相互竞争的前沿理论路线，依赖不同能源、材料、导航和实验条件。
- [ ] 每局固定真实可行性、关键未知量和失败阈值，玩家只能通过证据逐步缩小范围。
- [ ] 理论失败产生可用于能源、材料、传感器或聚变控制的次级成果。
- [ ] 合作、许可、保密和竞争沿用既有研发与AI公平信息规则。
- [ ] 图谱保证存在至少一条可完成路线，但不向玩家直接揭示答案。

## 工作流 B：巨型实验工程

- [ ] 定义深空试验场、能源阵列、特殊材料厂、导航阵列和原型装置的分阶段建设。
- [ ] 所有建设消耗真实库存、船厂、人员、能源、运输和多年排期。
- [ ] 试验产生局部环境、安全、设备损失和供应链风险，不通过随机事件直接删除无暴露资产。
- [ ] 玩家与AI可以围绕船厂、材料、理论和设施开展竞争或合作。
- [ ] 失败试验保留设备状态、遥测、证据和可恢复工程路径。

## 工作流 C：程序化目标星系

- [ ] 生成恒星质量、主要天体、轨道、卫星、环境和资源初始条件，物理规则与太阳系一致。
- [ ] 固定世界种子后，星系目录、星历和资源先验可重放且可迁移。
- [ ] 在探测前只暴露合理观测信息与置信区间，不泄露完整资源答案。
- [ ] 本地天体进入统一 `CelestialBody` 与星历接口，不另建简化玩法规则。
- [ ] 对生成结果运行稳定性、层级、碰撞风险和可玩交通地理筛选。

## 工作流 D：首次FTL飞行

- [ ] FTL只承担恒星际航段；行星附近仍使用常规推进、港口和补给网络。
- [ ] 定义启动区域、能量、装置质量、导航精度、准备时间和失败边界。
- [ ] 建造实验舰或装置，完成无人、载荷和可靠载人/商业前验证序列。
- [ ] 首次可靠飞行保存完整输入、遥测、结果和世界状态，支持确定性重放。
- [ ] 玩家可在科学突破后结束战役，或继续推进有限商业化和门户网络。

## 工作流 E：AI与文明级响应

- [ ] AI能评估独立研发、合作、许可、材料供应和暂不参与等策略。
- [ ] AI不能读取本局可行理论路线，只能使用自身证据和公开试验结果。
- [ ] FTL投资对普通市场、资本、劳动力、能源和运输产生真实挤出效应。
- [ ] 长期仿真验证项目不会因单一资源死锁，也不会无成本瞬间完成。

## 接口与存档变更

- 扩展 `TechnologyNode` 与证据系统以支持互斥理论、不完全可见和文明级合作。
- 新增生成星系数据包、星际航段、FTL试验、遥测与胜利状态。
- 保存太阳系既有资产与历史；FTL不能替换或删除常规航运网络。

## 自动验证

- [ ] `cargo run -p sim-tools -- research ftl-graph --seeds 1000` 保证至少一路可行、失败有成果且无信息泄露。
- [ ] `cargo run -p sim-tools -- generation systems --seeds 10000` 通过层级、稳定性与数据模式检查。
- [ ] `cargo run -p sim-tools -- scenario run first-ftl-flight` 完成材料、建设、试验与飞行全链审计。
- [ ] 多时间倍率、保存载入和并行求解下，理论结果与首次飞行重放一致。
- [ ] 长期经济仿真确认FTL投入的资源与机会成本真实反映到太阳系市场。

## 人工验收剧本

1. 从成熟外太阳系公司选择一条FTL理论并建设所需研究设施。
2. 完成至少一次失败或受限原型，利用所得证据调整路线。
3. 组织跨太阳系材料和能源供应，建成深空试验装置。
4. 生成并观测目标星系，执行首次可靠FTL航行。
5. 选择结束战役或继续建立第一条有限商业星际航线。

## 不纳入本版本

- FTL在行星附近自由启动或瞬间淘汰太阳系运输。
- 无工业、能源、材料和试验成本的科技树终点。
- 与太阳系采用不同物理规则的纯装饰随机星系。

## 退出条件

- [ ] FTL路线通过完整研发、原型、试验和认证链，而非抽象点数解锁。
- [ ] 第一次可靠星际飞行可重放、可解释并依赖既有文明能力。
- [ ] 程序化星系遵守统一目录、星历和物理接口。
- [ ] 科学胜利与有限商业化后续均可完成且存档稳定。
