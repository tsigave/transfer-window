# alpha-v0.4「市场与竞争」Checklist

## 版本目标

把固定合同板升级为由库存、生产、消费、人口和运力共同驱动的市场，并加入能够公平竞标、运营单船和影响运价的首批AI公司。

**前置依赖：** alpha-v0.3 退出条件全部通过。
**退出产物：** 动态市场、人口需求、预测、不完美信息、六家公司档案和AI单船运营。

## 工作流 A：存量、流量与价格

- [ ] 为经济节点实现按日生产、消费、订单、保留库存和产能约束。
- [ ] 为人口与产业建立按月变化的需求驱动，初期不逐居民模拟。
- [ ] 价格由当前库存、近期成交、未满足订单和可达运力形成，禁止无原因随机改价。
- [ ] 建立现货、运输服务和长期报价的订单簿基础，成交产生账本与库存预留。
- [ ] 市场详情页能解释价格变化的前三项原因和数据时刻。

## 工作流 B：预测与信息延迟

- [ ] 实现带置信区间的需求、价格和运力预测，历史预测不可被真实结果覆盖。
- [ ] 为市场公开数据定义发布时间和通信延迟；本版本地月范围可采用短延迟但保留字段。
- [ ] `CompanyKnowledgeView` 只包含公司可知数据、私有资产和带时间戳预测。
- [ ] 测试不能通过市场查询读取未来消费、未公开合同或其他公司私有计划。

## 工作流 C：AI公司基础

- [ ] 用数据配置六家主要公司档案、初始资产、现金边界、风险和评价权重。
- [ ] 实现执行层：接受/竞标合同、配载、补给、选已验证航迹、维护和异常放弃。
- [ ] 实现最小战术层：在未来数周为单船比较毛利、返程货源、违约风险、寿命与未来船位。
- [ ] AI只通过公开应用命令操作；调试审计可追溯每项资产和决策评分。
- [ ] 建立贪心基线策略，作为“只选当前最高毛利合同”的对照。

## 工作流 D：玩家竞争体验

- [ ] 合同支持公开竞标、截止时间、选择规则和失败反馈。
- [ ] AI占用的货物、泊位和合同实时反映在同一市场中，不能仅修改玩家价格。
- [ ] 提供竞争动态页面：已公开竞标、公司近期航次、市场份额和可观察资产。
- [ ] 允许玩家在竞标前查看自己的成本分解与预测风险，不显示AI私有底价。
- [ ] 价格冲击、货源短缺和新增需求生成新闻/解释事件，并能追溯实际原因。

## 接口与存档变更

- 新增生产线、消费计划、订单簿、预测快照、`AICompanyProfile`、`CompanyKnowledgeView` 和 `BidDecision`。
- 事件随机源拆分为经济和各AI公司命名流。
- 存档保存AI知识时刻、计划、预测历史和订单簿，迁移旧固定合同为公开订单。

## 自动验证

- [ ] `cargo run -p sim-tools -- economy conservation --years 2` 无来源不明的货物或资金。
- [ ] `cargo run -p sim-tools -- ai benchmark --scenario earth-moon --seeds 100` 输出AI与贪心基线对比。
- [ ] 信息隔离测试证明 `CompanyKnowledgeView` 不含未来事件和竞争者私有字段。
- [ ] 燃料短缺与需求暴增场景中，价格方向、合同量和AI响应符合因果断言。

## 人工验收剧本

1. 观察一个月的地月水与结构材料市场，展开价格变化原因。
2. 与至少两家AI竞标同一运输合同，验证赢家真实占用货物与泊位。
3. 抢先承运紧缺货物，确认后续价格与AI航次发生可解释变化。
4. 推进半年，检查六家公司没有凭空增加现金、舰船或货物。

## 不纳入本版本

- 多船战略规划、订船、融资和长期合同。
- 玩家及AI建设基础设施或研发技术。
- 火星完整商业开放。

## 退出条件

- [ ] 市场价格、库存和订单变化可追溯到真实存量与流量。
- [ ] 首批AI能持续完成合法航次，并在基准中优于贪心策略。
- [ ] AI信息隔离、账本审计和确定性测试通过。
- [ ] 玩家在标准剧本中能感受到合同和产能竞争，但仍有公平应对空间。

## 变更记录

- 初版：将AI从背景运力改为遵守同规则的市场参与者。
