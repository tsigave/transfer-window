# alpha-v0.2「可达空间」Checklist

## 版本目标

让所有登记天体成为可查询的航迹目标，并用统一舰船工程约束回答出发日、航程、载荷与工质之间的关系。尚未开放的区域可以规划、飞掠或执行无人任务，但不提供虚构服务。

**前置依赖：** alpha-v0.1 退出条件全部通过。
**退出产物：** 舰船物理模型、分级航迹求解、Pareto 查询、航行计划执行与复核。

## 工作流 A：舰船工程事实层

- [x] 定义模块化 `ShipBlueprint` 与 `VesselState`，包括干质量、货舱、聚变燃料、推进工质、功率、热和寿命。
- [x] 实现推力、有效排气速度、质量流率和推进功率的一致关系，金标准测试覆盖固定功率下的推力/比冲权衡。
- [x] 实现推进剂消耗、载荷、储备和非负质量约束；属性测试不能生成负质量或超舱容状态。
- [x] 实现反应堆功率、散热峰值、最大连续工作与累计寿命限制；不可行原因结构化返回。
- [x] 提供至少三种测试舰船和一艘无人探测器数据，明确标注虚构工程参数。

## 工作流 B：候选与执行级求解

- [x] 实现两体 Lambert 候选与 patched-conics 事件序列，经典转移案例达到约定误差。
- [x] 在出发窗口和航程范围内采样候选，区分无物理解、数值未收敛和搜索预算耗尽。
- [x] 实现分段有限推力优化，连续更新舰船质量、功率和热状态。
- [x] 使用独立自适应积分器复核候选，只有满足容差与储备策略的结果标为 `Executable`。
- [x] 求解器记录输入哈希、版本、容差、迭代次数和终止原因，保证问题可重现。
- [x] 对所有目录天体允许提交请求；无补给目标不自动添加燃料或捕获服务。

## 工作流 C：Pareto 与规划界面

- [ ] 以到达时间、工质、载荷、寿命消耗和估算成本进行非支配筛选。
- [ ] 从真实前沿选出最快、平衡、节能代表解；测试代表解一定属于可行集合。
- [ ] 实现出发日—航程热图、方案表和约束面板，显示计算进度、部分结果和取消状态。
- [ ] 展开页显示推力段、状态矢量、质量预算、功率/热峰值和误差余量。
- [ ] 未开发天体明确显示“无市场、无补给、无维修”，同时保留规划入口。

## 工作流 D：航行计划与确定性执行

- [ ] 实现 `QuoteTransfer`、`ValidateTransfer`、`ScheduleVoyage` 和 `CancelPlan`。
- [ ] 提交前重新验证舰船、载荷、出发时刻和输入哈希；过期解以 `SOLUTION_INVALIDATED` 失败且无扣款。
- [ ] 将批准方案拆成推力、滑行、接近和抵达事件，按事件队列推进。
- [ ] 执行结束比较计划与实际状态、工质和寿命消耗，超容差时生成诊断而非强行吸附目标。
- [ ] 航行中保存载入及不同时间倍率产生同样的抵达状态哈希。

## 接口与存档变更

- 新增 `ShipBlueprint`、`VesselState`、`TransferRequest`、`TransferSolution` 和航迹段类型。
- 存档增加舰船、活动航行计划、求解器版本和执行误差；模式迁移保留 alpha-v0.1 存档。
- 求解查询无副作用；只有计划命令创建世界事件。

## 自动验证

- [x] `cargo run -p sim-tools -- trajectory golden` 通过两体、patched-conics 和有限推力金标准。
- [x] `cargo run -p sim-tools -- trajectory catalog-smoke` 对每个登记天体至少得到结果或结构化不可行原因。
- [ ] `cargo run -p sim-tools -- replay voyage --rates 1,100,10000` 的抵达状态与消耗一致。
- [ ] 普通地月/地火代表方案在目标硬件 5 秒内出现，超时可取消且无残留任务。

## 人工验收剧本

1. 为同一艘船比较三个地月出发日，观察航程、工质与载荷变化。
2. 选择一个可执行方案，推进到抵达并核对计划/实际误差。
3. 为木卫四与海卫一提交请求，确认可规划且界面明确无当地服务。
4. 修改舰船载荷后尝试提交旧方案，确认安全失效并可重新求解。

## 不纳入本版本

- 动态货物市场、合同结算和经营财务。
- 引力弹弓全局搜索、气动捕获和 Oberth 高级策略。
- 玩家基地、补给站与维修网络。

## 退出条件

- [ ] 全部登记天体进入统一规划入口。
- [ ] 航迹规划与实际执行在定义容差内一致。
- [ ] 工质、功率、热和寿命约束不能被 UI 或跳时绕过。
- [ ] 自动与人工验收通过，无阻断级数值稳定问题。

## 变更记录

- 初版：把“可通航”和“可开发”拆为独立权限与能力。
- 舰船工程事实层：完成工作流 A；证据为 `sim-engineering` 金标准与属性测试，以及 `sim-tools engineering audit` 对四套虚构蓝图的模式审计。
- 航迹候选与复核：完成工作流 B；`trajectory golden` 验证经典两体、patched-conics、有限推力和独立积分，`trajectory catalog-smoke` 验证全部登记天体的统一请求入口。
