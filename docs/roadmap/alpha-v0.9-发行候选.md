# alpha-v0.9「发行候选」Checklist

## 版本目标

停止扩张核心系统范围，把 alpha-v0.8 的完整游戏整理为可学习、可平衡、可恢复且达到性能预算的候选产品。验证研究路线和六家AI能在不同种子下持续形成经营局面。

**前置依赖：** alpha-v0.8 退出条件全部通过。
**退出产物：** 标准战役、教程、平衡基线、性能报告、存档迁移演练、无障碍与故障恢复。

## 工作流 A：标准战役与内容冻结

- [ ] 冻结 2160 标准剧本的开局资产、节点、人口、库存、公司档案和世界种子规则。
- [ ] 完成从地月新公司到木星运营商的阶段目标、提示、失败/重组与战役完成判定。
- [ ] 科技图谱达到 35–50 个有效节点，每方向至少一条三层成熟路线和一个前沿节点。
- [ ] 冻结基础货物、设施、舰船模块、合同和AI档案的首发清单，记录数值调整依据。
- [ ] 为自定义剧本保留数据入口，但不以编辑器作为版本出口。

## 工作流 B：教程、信息层级与无障碍

- [ ] 制作可跳过、可重新进入的教程：第一份合同、航迹比较、维护、舰队、建设、研发和木星远航。
- [ ] 所有关键数值可下钻到来源、单位、数据时刻和不可执行原因。
- [ ] 为色觉缺陷提供非颜色编码，为缩放、键盘操作、动效降低和暂停提示提供设置。
- [ ] 复杂页面提供运营摘要、规划详情和工程数据三级展开，信息来自同一权威状态。
- [ ] 建立术语表和上下文帮助，避免要求玩家预先掌握轨道力学符号。

## 工作流 C：平衡与AI长期仿真

- [ ] 建立多随机种子十年无玩家、基准玩家和多策略自动玩家仿真。
- [ ] 统计破产率、市场集中度、运价、交付率、科技扩散、舰型多样性和木星开发时刻。
- [ ] 六类AI在现金缓冲、合同期限、舰型、研发和投资组合上产生可测差异。
- [ ] AI多数种子维持偿付能力，破产与垄断结果必须能从资产和决策追溯。
- [ ] 校准标准开局，使新玩家有恢复空间，同时放弃机会会被AI公平占据。
- [ ] 建立平衡变更报告，数值修订必须指向目标指标而非主观感受。

## 工作流 D：性能、稳定性与恢复

- [ ] 在目标硬件运行 40+ 天体、30 节点、1,000 活动舰船、六家AI的性能场景。
- [ ] 达成星历、首批航迹、经济日结、月跳时、保存和载入预算，记录P50/P95。
- [ ] 优化缓存、后台求解和UI虚拟列表，保留金标准及确定性测试。
- [ ] 注入求解取消、磁盘写满、异常退出、损坏存档和迁移失败，提供安全恢复及可读错误。
- [ ] 建立自动备份轮换和迁移前备份；恢复不会覆盖唯一健康存档。
- [ ] 连续运行长时压力测试，确认内存、事件队列、日志和存档体积保持预算内。

## 工作流 E：存档迁移与发布质量

- [ ] 收集 alpha-v0.1 至 alpha-v0.8 的代表存档夹具并逐级迁移到当前模式。
- [ ] 不可迁移内容必须阻止载入并说明版本、字段和恢复方式，不静默删除。
- [ ] 建立崩溃报告导出，包含版本、种子、命令摘要且不包含个人路径。
- [ ] 运行安装、首次启动、更新、卸载和保留存档测试。
- [ ] 锁定阻断/严重/一般缺陷标准和发布候选签收流程。

## 接口与存档变更

- 原则上不新增核心领域系统，只允许为可用性、恢复和性能增加兼容接口。
- 固化存档迁移链、内容包校验、自动备份和诊断导出格式。
- 所有破坏性模式变更必须在此版本结束前完成并提供迁移。

## 自动验证

- [ ] `cargo run -p sim-tools -- campaign simulate --seeds 500 --years 10` 生成平衡报告。
- [ ] `cargo run -p sim-tools -- ai audit --all-companies` 无隐藏资金、物资、技术或未来信息访问。
- [ ] `cargo run -p sim-tools -- perf alpha-v1-target` 满足技术规格预算。
- [ ] `cargo run -p sim-tools -- save migrate-fixtures` 通过全部代表存档与故障注入。
- [ ] 共同验证命令及端到端UI测试连续三次无随机失败。

## 人工验收剧本

1. 一名未阅读设计文档的测试者仅通过教程完成首份地月合同。
2. 从标准开局推进到第一座自有设施、第一项中级认证和第一艘自研舰船。
3. 建立木卫四业务并维持两个供应周期，过程中至少处理一次竞争和一次供应冲击。
4. 强制退出后恢复最近健康存档，并确认任务、账本和AI计划一致。

## 不纳入本版本

- 新的可开发行星区域或新的核心经营系统。
- 完整外太阳系开发、FTL和程序化星系。
- 持久在线世界与网络功能。

## 退出条件

- [ ] 标准战役、教程、研发和AI长期仿真达到批准指标。
- [ ] 性能、恢复、迁移和无障碍检查通过。
- [ ] 无阻断或严重缺陷；一般缺陷有明确处置版本。
- [ ] 内容和接口冻结，可进入 alpha-v1.0 最终签收。

## 变更记录

- 初版：将此版本限定为收敛和验证，不继续扩张系统。
