# alpha-v0.1「完整太阳系」Checklist

## 版本目标

建立可查询、可推进、可保存的统一太阳系事实层。玩家能在地图中看到太阳、八大行星、主要矮行星、关键卫星和代表性小天体；本版本不提供航迹求解或经营玩法。

**前置依赖：** 无
**退出产物：** 技术骨架、版本化天体数据包、星历服务、太阳系浏览器、确定性事件队列和存档骨架。

## 工作流 A：项目与质量骨架

- [x] 建立 Rust workspace、React/Vite/Tauri 应用和只读调用样例；`cargo test --workspace` 与 `npm run build` 均通过。
- [x] 配置格式、Clippy、TypeScript、前端测试和文档链接检查；CI在干净环境执行共同验证命令。
- [x] 建立领域包依赖规则，自动检查核心包不依赖 Tauri、React 或渲染代码。
- [x] 定义错误码、日志字段、稳定ID和带单位新类型；测试拒绝无效ID、NaN、无限值与错误单位。

## 工作流 B：时间、坐标与天体目录

- [x] 实现 TDB 内部时间、显示日历转换和局部历元；往返转换测试覆盖标准历元、闰秒边界显示和百年跨度。
- [x] 实现带 `frame_id` 的状态矢量及日心/父天体局部坐标转换；往返误差满足精度预算。
- [x] 建立版本化 `CelestialBody` 数据模式，包含来源与质量等级；模式校验能报告字段路径。
- [x] 收录基础设定规定的全部初始天体；`sim-tools catalog audit` 报告无重复ID、无缺失父级、无层级环。
- [x] 建立小行星带、半人马和柯伊伯带区域对象；区域不得伪装成可着陆独立天体。
- [x] 将所有天体初始状态设为至少 `Observed`，并验证开发权限不影响目录加载。

## 工作流 C：星历与地图

- [x] 实现按时刻查询的解析星历接口与缓存，返回位置、速度、参考系、质量等级和来源。
- [x] 为太阳、行星、月球和至少各一个外行星卫星建立公开参考数据金标准样本。
- [x] 对全部天体运行 200 年采样，确保状态有限、轨迹连续且父子关系合理。
- [x] 实现太阳系搜索、层级列表、连续时间控件和 Three.js 3D 地图；支持相机缩放、视角切换和进入行星局部层级，每个登记天体都可定位并查看基础数据。
- [x] UI明确区分真实尺度数据与视觉放大，切换时刻不会把显示坐标写回模拟状态。

## 工作流 D：事件与存档骨架

- [x] 实现按时间、优先级和稳定ID排序的 `ScheduledEvent` 队列，同刻事件顺序有测试。
- [x] 实现暂停、倍率和 `AdvanceUntil`；同一空世界跨多种推进方式产生相同状态哈希。
- [x] 建立 SQLite `GameSnapshot`、事件队列、内容版本和随机流状态模式。
- [x] 保存采用事务和原子替换；注入写入中断后仍能载入最后一个完整快照。
- [x] 完成新建、保存、载入和损坏存档错误界面，不静默重置世界。

## 接口与存档变更

- 新增 `CelestialBody`、`BodyState`、`DevelopmentStatus`、`ScheduledEvent`、`GameSnapshot`。
- 首个存档模式记为 `save_schema = 1`，首个天体内容包记为独立内容版本。
- 查询接口：列出/搜索天体、获取指定时刻状态、获取层级和地图采样。

## 自动验证

- [x] `cargo run -p sim-tools -- catalog audit` 覆盖全部约定天体并输出清单校验和。
- [x] `cargo run -p sim-tools -- ephemeris verify --span-years 200` 满足按数据等级定义的误差阈值。
- [x] `cargo run -p sim-tools -- replay empty-world --rates 0,1,100,10000` 的最终哈希一致。
- [x] 共同验证命令全部通过，测试报告归档到版本验收记录。

## 人工验收剧本

1. 新建 2160 标准世界，在层级中搜索地球、谷神星、木卫四、海卫一和阿罗科特。
2. 分别定位并查看父天体、物理参数、星历来源与开发状态。
3. 推进十年，确认地图位置连续且 UI 保持响应。
4. 保存、关闭、载入，确认时间、选中天体和全部状态一致。

## 不纳入本版本

- 航迹规划、舰船、合同、市场和建设。
- 逐颗模拟全部已知小行星或柯伊伯带天体。
- 航迹规划使用的执行级 3D 轨道分析视图；本版 Three.js 仅用于事实层浏览和视觉插值。

- [x] 所有工作流和自动验证完成。
- [x] 初始天体目录无缺项，全部可搜索、定位和查询星历。

- [x] 人工验收剧本通过并保存证据。
