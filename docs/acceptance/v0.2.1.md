# v0.2.1 验收记录

本记录验证 alpha-v0.2 功能从 Tauri/浏览器预览边界迁移到正式网页前后端架构。领域规则、存档 schema 与航迹求解器保持兼容。

验收日期：2026-08-14（America/Los_Angeles）

## 架构验收

- `sim-server` 独立组合 `sim-app`、`sim-trajectory` 和 `sim-save`，领域 crate 不依赖 HTTP、React 或 Tauri。
- React 的运行时、航迹与存档客户端只访问 `/api/v1`；生产 bundle 不再包含 `@tauri-apps/api` 或 `browser-preview-v1`。
- 航迹任务使用 `202` 创建、SSE 推送、GET 状态恢复和 DELETE 取消；权威结果携带请求、世界修订、求解器版本和执行级误差。
- 排期继续经过输入哈希、世界修订和 `Executable` 复核；服务器推进按事件边界执行。
- SQLite 存档只由服务端读写；旧浏览器视图仅在默认槽不存在时导入一次并保留原键。
- API 默认只监听回环地址，非回环绑定需要显式授权；公开部署要求由反向代理提供认证、TLS 和限流。

## 发行边界

生产发行物由 `cargo build -p sim-server --release` 和 `npm run build` 生成。当前是单玩家、单租户服务，不承诺多账号或共享世界。Tauri 源码保留但 `bundle.active` 为 `false`，不属于 v0.2.1 发行物。
