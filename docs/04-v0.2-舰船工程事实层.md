# v0.2 舰船工程事实层

本文定义 alpha-v0.2 首个实现切片的权威输入与计算边界。实现位于 Rust `sim-engineering` 领域包；版本化数据位于 `data/engineering/ships-v1.json`。界面和未来航迹求解器只能读取这些结果，不能另行实现质量、推力、功率、热或寿命规则。

## 数据模式与单位

舰船目录模式版本为 `1`，内容版本为 `engineering-ships-v1`。目录加载时校验模式版本、内容版本、蓝图修订、稳定 ID、模块完整性、模块干质量之和、功率链路和限制范围，并在失败时返回字段路径。除无量纲效率、修订号、名称和角色外，数值统一采用 SI：

| 字段后缀 | 单位 | 约束 |
| --- | --- | --- |
| `_kg` | 千克 | 有限且非负；蓝图干质量必须大于零 |
| `_m3` | 立方米 | 有限且非负 |
| `_w` | 瓦 | 有限且非负；声明的可用功率必须大于零 |
| `_j` | 焦耳 | 有限且非负；热缓冲上限必须大于零 |
| `_s` | 秒 | 有限且非负；寿命与连续工作上限必须大于零 |
| `_mps` | 米/秒 | 有限且大于零 |
| `_k` | 开尔文 | 有限且大于零 |
| `_j_per_kg` | 焦耳/千克 | 有限且大于零 |

目录中的四套蓝图均是 2160 标准剧本的虚构玩法参数，不是现实设计或性能声明：三艘有人货船和一艘无人探测器都以 `engineering_basis = fictional` 标注，目录顶层也包含相同性质的声明。

## 推进与消耗关系

推进输入是持续时间、电推进输入功率和有效排气速度。电能到喷流的效率为 `η` 时：

```text
jet_power = η × input_power
thrust = 2 × jet_power / effective_exhaust_velocity
mass_flow = thrust / effective_exhaust_velocity
specific_impulse = effective_exhaust_velocity / standard_gravity
```

反应堆输出等于推进输入功率加基础负载；聚变燃料消耗由反应堆电能输出除以蓝图的单位质量可用电能得到。推进工质和聚变燃料保持为两个独立库存。

废热由反应堆废热、推进转换损失和基础负载组成。连续散热能力先抵消废热，超出部分进入峰值热缓冲，低于散热能力时则释放已有缓冲。反应堆和发动机寿命都按相对额定功率折算为等效全功率秒。

## 约束、默认值与错误

`VesselState` 在计算前校验蓝图修订、载荷质量与体积、两类燃料容量、热缓冲、连续工作和累计寿命。燃烧请求还校验排气速度范围、推进总线、反应堆功率、工质与聚变燃料储备、峰值散热、最大连续工作和寿命储备。

储备策略没有隐式游戏加成。调用方未指定时使用显式的零储备默认值；实际航迹请求应构造自己的 `ReservePolicy`。不可行结果无状态变更，并返回一个或多个结构化 `ConstraintViolation`：稳定错误码、字段名、所需值、可用值和单位。可行结果只有通过 `apply_burn` 才更新舰船状态。

## 验证入口

```bash
cargo test -p sim-engineering
cargo run -p sim-tools -- engineering audit
```

测试包含固定功率下推力/比冲权衡的金标准、结构化不可行原因和生成式属性测试。属性测试对持续时间、功率、排气速度、载荷及燃料装载进行采样，确认可行燃烧不会生成负质量或超容量状态。
