# v0.2 航迹求解与复核

alpha-v0.2 的无副作用航迹查询由 Rust `sim-trajectory` 领域包负责。查询读取 `sim-astro` 星历与 `sim-engineering` 舰船状态，不创建世界事件，也不改变舰船或资源；只有后续应用命令能够提交方案。

## 输入与分级结果

`TransferRequest` 指定始发和目的天体、出发窗口、航程范围、舰船、载荷、储备策略、抵达条件及搜索预算。所有登记天体都允许作为目标；开发状态不参与请求准入。始发与目标相同、倒置窗口、无效采样数或超容量载荷会在采样前返回 `INVALID_REQUEST`。

搜索在出发窗口和航程范围内确定性均匀采样。每个采样点得到可执行方案或结构化失败：

- `NO_PHYSICAL_SOLUTION`：几何奇异或当前零圈 Lambert 分支无物理解；
- `NUMERICAL_NON_CONVERGENCE`：候选或独立积分没有在预算和容差内收敛；
- `CONSTRAINT_VIOLATION`：舰船的工质、功率、热、连续工作或寿命约束不满足；
- `SEARCH_BUDGET_EXHAUSTED`：保留已完成的部分结果后停止；
- `CANCELLED`：响应取消令牌并保留已完成的部分结果。

进度回调报告已计算数、计划总数、当前可执行解数量和状态。结果携带输入 BLAKE3、求解器版本、Lambert 迭代数、积分步数、容差和终止原因；同一输入可以独立重现。

## 候选与 patched conics

候选层使用通用变量零圈 Lambert 求解日心两体转移，并返回出发和抵达状态矢量。随后以天体本地停泊轨道能量关系计算出发逃逸和抵达接近事件：

```text
local_delta_v = sqrt(v_infinity² + 2 μ_body / parking_radius)
                - sqrt(μ_body / parking_radius)
```

每个方案显式记录出发逃逸、日心转移和抵达接近事件。当前版本不搜索引力弹弓、气动捕获或 Oberth 策略；这些能力仍按路线图排除。

## 分段有限推力

Lambert 的脉冲速度需求会转换成有限推力工程计划。优化器在蓝图允许的有效排气速度与功率组合中搜索，使用火箭方程估算工质，再通过 `sim-engineering` 逐段消耗工质和聚变燃料，并连续累计热缓冲、反应堆等效全功率时间和发动机寿命。

长时间点火拆成不超过六小时且不超过蓝图连续工作上限的推力段；段间包含散热和停机间隔。出发和抵达机动总耗时若占航程一半以上，候选按约束不可行返回。滑行后热缓冲与连续工作计时重置，累计寿命及库存不会重置。

## 独立执行级复核

通过工程约束的 Lambert 候选还不能直接标记为 `Executable`。独立复核器使用自适应 RK4 步长加倍和 Richardson 修正，在同一日心引力场中重新积分候选出发状态，并将抵达位置和速度与 Lambert 终点比较。只有误差同时小于请求声明的米和米每秒容差、储备仍满足且积分未耗尽预算时，结果才是 `Executable`。

未开发目标的 `DestinationServices` 明确为无市场、无工质补给和无维修；飞掠或抵达不会凭空补充库存。

## 验证入口

```bash
cargo run -p sim-tools -- trajectory golden
cargo run -p sim-tools -- trajectory catalog-smoke
```

`golden` 覆盖经典 Lambert 速度样本、地球停泊轨道 patched-conics 能量关系、地月分段有限推力和独立积分复核。`catalog-smoke` 对 41 个登记天体逐一提交请求，要求每个目标至少得到 `Executable` 或上述结构化不可行原因。
